# Agents page: 25 improvements, answer sheet

How the page works, in short: `night-shift/index.html` draws an isometric building on one canvas. Each room has a kit of furniture and stations; every agent is a resident that walks between stations (or runs to the ballroom when the tune changes). Extras sit on top of that: Wifeo's family, the cats, the bouncers, the wormhole to the homepage, the smoke machine and the lights. The text above the building comes from the real agent runs (site patrol, daily agents) and from admin settings (custom agents, renamed agents, lines).

Answer each with **Y** (do it), **N** (skip), **L** (later) or **M** (do it, but my way: note it). I fill in the sheet as we go.
