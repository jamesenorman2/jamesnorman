    How it works

    Delay

    Barriers buy time

    A fence, a door or a strongroom doesn’t stop a determined attacker; it slows them down. Delay is only useful if someone is coming.

    Detect

    Early beats late

    Detection counts when there is more delay still ahead than the time it takes to assess the alarm and respond. Detecting someone at the vault door is too late.

    Critical detection point

    The last useful moment

    The point on the path after which detection can no longer lead to interruption. Good systems detect before it, with as much delay after it as possible.
